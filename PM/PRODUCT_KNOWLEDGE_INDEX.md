## Knowledge precedence

1. Default-branch files and merged PR commits establish the current repository baseline.
2. Tags establish named historical snapshots.
3. Open PRs and branch-only files establish recoverable candidates, not approved architecture.
4. Issues establish intent and acceptance criteria, not implementation completion.
5. Where multiple generations exist, this index preserves all of them and does not select or synthesize a replacement.
