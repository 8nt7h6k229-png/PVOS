## Evidence and status rules

- **Main**: the cited asset is present on the default branch or its commit is an ancestor of the default branch.
- **Branch-only**: the cited commit or document is reachable from a GitHub branch but not the default branch.
- **Deprecated**: the branch has no unique commits, or Git ancestry proves that a named successor contains it. This means obsolete for *independent knowledge recovery*, not authorization to delete the branch.
- **Experimental**: GitHub records an open/draft work item, or a named branch contains no unique implementation commit. Experimental does not mean approved product knowledge.
- Issues and PRs prove intent and workflow state. Commits and documents prove the recovered content.
