## Objective

Provide a bounded Windows engineer workflow that launches the existing C# PVOS authority, runs existing Python evidence validation and emits a readable PASS/FAIL/BLOCKED report.

## Scope

1. Controlled Windows double-click launcher (`.bat` or equivalent).
2. Governed repository and approved evidence preflight.
3. Obvious default input/evidence entry point using current approved assets.
4. Invocation of existing Release C# CLI and Python validator.
5. Human-readable summary plus machine-readable evidence report.
6. Deterministic run/report identity where inputs and evidence are unchanged.
7. Useful prerequisite, execution and evidence error handling.
8. Minimal operator instructions and bounded automated tests.
